# Algorithm Lab: Search Strategies
This interactive tool is designed to help students visualize and compare two fundamental search strategies used in computer science: Linear Search and Binary Search.

Try it : https://search-algorithms-binary-vs-linear-wslisam.pages.dev/

## 🚀 How to Use this App
Set a Target: Pick a number between 1 and 31 in the input box.

Start the Race: Click the "Start" button to see both algorithms try to find your number simultaneously.

Observe the Difference:

Watch how Linear Search checks every single box.

Watch how Binary Search smartly cuts the search area in half each time.

Analyze: Look at the "Steps" counter to see which one was more efficient for your specific number.

## 💡 What You Will Learn
The Power of Halving: You'll see why Binary Search is the go-to choice for large, sorted datasets.

The Importance of Order: Reflect on why Binary Search requires the numbers to be sorted before it can work.

Best vs. Worst Case: Try setting the target to 1 or 31 and see how the algorithms react differently!

## 🧠 Think About It
Once you finish the simulation, check out the Think & Link section at the bottom to see how these concepts apply to massive amounts of data (like Google Search or your phone's contact list).
